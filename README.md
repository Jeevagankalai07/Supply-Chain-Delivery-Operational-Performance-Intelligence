# Supply Chain – Delivery & Operational Performance Intelligence

**Supply Chain analytics project using SQL and Power BI to analyze delivery performance, sales trends, and product profitability.**

## Project Overview
Analyzed the DataCo Smart Supply Chain dataset to identify delivery issues, understand sales performance, and generate actionable business insights.

## Tools & Technologies
- SQL – Google BigQuery
- Power BI – Dashboard Development
- Excel – Data Handling

## Key Highlights
- Analyzed 180,519 order items.
- Identified a 54.83% late delivery rate.
- Compared actual and scheduled delivery times.
- Analyzed sales across customer segments and regions.
- Evaluated product and category profitability.
- Studied the relationship between discounts and profit.

## Project Structure
- `SQL_Results/` – SQL query output files
- `Power BI Dashboard/` – Interactive dashboards
- `Documentation/` – Business analysis documentation
- `Supply_Chain_Analysis.sql` – SQL analysis queries

## Business Value
Provides insights to improve delivery performance, optimize discount strategies, and support data-driven business decisions.
